这是一份代码阅读方法演示。

## 从问题出发

先写下这次要回答的问题。比如“这个按钮为什么没有请求”，就沿着事件、状态和请求调用往下走。

## 留下最小地图

```text
页面入口 → 用户动作 → 状态变化 → 请求适配 → 后端接口
```

每找到一个关键位置，记下它回答了什么，而不是只收藏文件名。

## 判断自己是否真的理解

关掉AI解释，试着用三句话描述：入口是什么、关键判断是什么、如何验证结果。如果说不清，回到这条链路继续看。
