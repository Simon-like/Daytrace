# READER-002：完整 Markdown 正文阅读专项

用户要求在动效实施后继续施工到完整 Markdown 渲染，并检查页面效果。本任务在 MOTION-002 完成后启动，负责正文语义、排版与交互闭环。

## 范围

- 保留 marked 服务端单次 token 解析、安全 URL／附件映射、原始 HTML 拒绝和输出清洗，不重开解析框架。
- 将代码工具栏、表格横滑容器、图片按钮／说明等语义结构前移到服务端 HTML，减少 hydration 后 DOM 搬动与布局变化。
- 重新整理中文正文、标题、列表、引用、任务列表、删除线、行内代码、长链接、代码、表格、图片、目录和后续补充的响应式排版。
- 客户端只保留复制、溢出观察、图片错误与灯箱等必要增强；复制失败、缺图、未知语言和不支持语法保持可读反馈。
- 用现有技术／菜谱／随想合成记录覆盖完整阅读，补必要样例与测试；不改变公开／私密权限边界。

## 基线与写入

依赖 MOTION-002。新 worktree 从届时最新主分支创建，并以补丁带入尚未集成的 UI-001、MOTION-001、MOTION-002 交付；不得覆盖任何原工作区。允许修改 board 中的 Markdown 解析器、reader、测试、合成示例、契约说明、计划、报告和证据。

## 验收

- CommonMark／GFM 支持项和危险输入负例通过；HTML 与目录仍来自同一 token 流。
- 代码复制不含按钮文字，宽代码／表格仅局部横滑；图片有尺寸、替代文本、缺图反馈、灯箱关闭恢复。
- 320–1440 多视口无整页横溢出，移动中文正文保持 17–18px 起始方向，键盘与减少动态效果等价。
- lint、typecheck、单元／集成／浏览器测试和 build 通过；保存截图与实际资源测量，正文脚本预算不静默标通过。
- 最终提供可由 Kimi Work 重启的本地预览根目录，停止本轮临时验证服务器。
