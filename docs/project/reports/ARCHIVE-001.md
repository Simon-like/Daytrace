# ARCHIVE-001 交接

桌面与 H5 归档支持按当前筛选继续读取公开记录；初始和后续请求统一每页 50 条，加载失败可重试或从头读取。标签从完整公开投影汇总，读取不完整时提示；H5 无标签时隐藏空标签区。筛选面板未提交的选择不再冒充已应用条件。

验证：Node 24.18.0，typecheck、lint、单元测试 66/66、项目文档检查通过。隔离 Nest 使用 61 条合成公开记录，实际分页读取 50+11 并找到末页标签；桌面与 H5 Chromium 使用合成 API 响应分别验证 50+11 的加载交互。两项验证分别覆盖真实服务和浏览器，尚未构成同一数据集的端到端测试，也未做真实 iPhone/Safari 验证。既有公开投影测试覆盖私密记录隔离。

限制：完整标签目前通过逐页读取所有公开摘要汇总，内容量大时会增加服务端请求及页面等待；后续应考虑服务端公开标签聚合及缓存。已有工作区生成文件和素材未纳入本任务。未合并 main、未部署。
