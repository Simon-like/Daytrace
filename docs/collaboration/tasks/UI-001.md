# UI-001：前端信息架构与本地组件体系重塑

用户反馈当前Demo信息编排混乱、内容过满、原生控件与焦点样式未完成，并要求先解决主题风格和模块编排，再单独重新实现Markdown解析渲染。推荐Tailwind CSS与无头组件，本地维护组件库，并调研优秀阅读型界面。

## 本轮范围

- 诊断用户三张截图，调研个人档案/编辑型阅读界面、渐进披露和Tailwind+无头组件方案，记录来源与采用/不采用理由。
- 保留D/D²深橄榄、矿物纸白、中文宋黑搭配与有限手写，不推翻品牌方向；以减少竞争模块、隐藏次级复杂度和统一排版节奏为主。
- 建立Tailwind CSS v4设计令牌和本地UI组件：Button、Input、Select、Checkbox；无头行为采用按需安装的Radix Primitives，样式源码由本仓库维护。
- 重构桌面/移动shell、首页、归档筛选、公开搜索和记录列表；修正全局控件焦点及正文页明显容器挤压/裁切，不重写Markdown解析器或reader正文组件。
- 更新相关浏览器/单元测试与真实运行截图，明确本轮未完成的Markdown专项和后续组件迁移。

## 写入与集成

这是共享前端集成任务，允许修改board中列出的app/shared layouts/components、records/search、站点依赖和锁文件。不得改API、权限、内容数据、PRD验收门槛或生产配置。基于最新主分支的独立`agent/UI-001/design-system` worktree交付；中央board只在主checkout维护。

## 验收

- 首页只有一个主要内容焦点，分类与手写不再形成重复竞争；归档标签默认不全部铺开。
- Select、Checkbox、搜索输入与按钮无浏览器默认皮肤/异常描边，具备可见且统一的键盘焦点、disabled状态和减少动效适配。
- 现有筛选、搜索、返回恢复、移动导航等功能不回归；正文页无不合理窄列或顶部裁切。
- lint、typecheck、相关单元/集成测试、真实Chromium关键路径和多视口检查通过；保留实际证据与未验证边界。
