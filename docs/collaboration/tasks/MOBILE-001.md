# MOBILE-001：独立移动 H5 应用与触摸导航

依赖 SYSTEM-001 的共享设计和内容资产。移动端不是桌面媒体查询的延续，而是同一 monorepo 内独立的 `apps/h5` 应用，具有自己的信息优先级、导航和页面编排。

## 范围

- 新建 Next.js / React / Tailwind 的 `apps/h5`，复用共享令牌、控件、品牌和公开内容能力，不复制 Nest 业务接口。
- 使用独立顶部品牌区与底部主导航，处理 safe-area 和触摸目标；不再使用桌面侧栏或汉堡菜单充当完整移动导航。
- 首页按移动阅读优先级重排；归档使用底部筛选面板与已选摘要；搜索为独立检索界面；阅读页保持 17–18px 正文、局部代码／表格横滑与图片能力。
- 提供明确 `/h5/` 入口及独立开发端口；主站只做经过验证的代理，不未经测试加入 UA 自动跳转。
- 增加移动导航、筛选恢复、搜索、阅读和减少动态效果测试，保存真实 Chromium 移动视口截图。

## 基线与写入

从最新主分支创建独立 worktree，并带入 SYSTEM-001 及前序未集成交付。只修改 H5 应用、必要的预览代理／启动脚本、H5 测试、依赖锁定和本任务文档；共享包新增能力先交接，不在本任务静默重写桌面页面。

## 验收

- 320、390、430、768 视口无整页横溢出，底部导航和筛选抽屉可触摸、可键盘关闭，safe-area 不遮正文。
- 首页、归档、搜索、阅读均为独立移动编排，共享公开内容，无第二套权威 API。
- `/h5/` 页面、静态资源和 `/api/v1` 请求路径正确，快速返回和筛选状态可恢复。
- H5 build、typecheck、浏览器测试与桌面回归通过；临时服务在交付前停止。
- 明确 Chromium 视口不等于真机 iPhone／Safari 验收。
