# 功能模块页面设计 v1.0

日期：2026-10-30。阶段：M1 体验设计切片。方向：D/D² 档案主题，保留手写注记。本文件描述本轮实际原型，不代表正式内容与权限系统完成。

原型位置：`design/contributions/2026-10-30-codex-modules-v1/`。本地预览入口为 `review.html`（模块对照）与 `index.html`（可操作页面）。

## 1. 本轮模块

| 模块 | 桌面排版 | 手机排版 | 可操作内容 |
| --- | --- | --- | --- |
| 首页 | 深橄榄档案栏；引言与手写短注；技术与厨房双栏；原想法与后来补充；近期记录 | 顶栏、引言、段后手写、技术、厨房、随想、近期记录依次单列 | 实际记录链接、导航和搜索 |
| 全部记录/索引 | 日期分组，标题/摘要/标签组合，关键词与类别表单 | 搜索占整行，类别与提交第二行；记录保留日期，标签可换行 | 组合筛选、清除、无结果、URL 状态、浏览器后退 |
| 技术长文 | 主阅读列 + 侧边目录/手写提醒；代码和排查表分区 | 有意控制示例长标题断行；展开式目录，图解字号保持；宽代码和表格各自横滑 | 目录定位、代码复制/失败反馈、目录活动项、原文补充 |
| 生活菜谱 | 标题、实践信息、独立照片；材料窄列与步骤主列 | 图片后先材料再步骤，宽度足够时材料两列；小屏材料单列 | 照片放大与关闭、步骤阅读、后续调整 |
| 随想认知 | 较窄的独立阅读列，原话、手写摘句和后来补充 | 同一内容顺序单列，手写摘句不压正文 | 多条独立随想样本、回到记录、下一条 |
| 关于 | 说明主列 + 内容类型旁注 | 旁注移到主内容下方 | 浏览介绍与进入记录，不编造个人履历或社交链接 |
| 找不到页面 | 简短状态与继续浏览的入口 | 保留相同层次与触摸空间 | 全部记录、搜索；无私密存在性提示 |

全部内容是公开设计样本。未放入任何真实私密内容；本轮没有用前端过滤伪装权限。

## 2. 共用系统

- 颜色、字体、间距与动效变量位于 `tokens.css`，页面结构样式位于 `styles.css`。
- 标题采用本机宋体栈，正文采用中文黑体栈，日期/代码等宽；手写采用本机楷体栈，避免本轮引入大字体下载。
- 没有找到对应本机字体时会回退，跨系统字体差异尚需后续锁定字体方案；当前不是全平台字体冻结。
- 手写保留三种职责：引言短注、页边提醒、后来认识的局部强调。没有把导航、正文、代码变成手写体。
- 标准锚点、原生链接、原生 dialog，使用浏览器自然滚动。没有滚动接管或逐段强制入场。

## 3. 断点与内容重排

| 条件 | 实际行为 |
| --- | --- |
| 大于 1180px | 148px 档案栏，首页技术/厨房双栏，详情右侧目录 |
| 981–1180px | 116px 档案栏和较小间距；紧凑技术图解分为两行，仍保持文字尺寸 |
| 761–980px | 仍保留侧栏；详情目录改为展开式，减少正文被挤窄；首页按实际宽度分配双栏 |
| 不大于 760px | 顶栏取代侧栏，首页和详情单列，菜单/搜索独立弹层；材料列表可两列 |
| 不大于 359px | 内边距20px，标题调整，材料列表改为单列 |

验证覆盖边界前后，不仅检查几个设备名称。图解改用原生 HTML 文本布局，避免固定 SVG viewBox 把中文标签缩成不可读小字。

## 4. 交互与状态

- 搜索：实际检索本轮六条样本的标题、标签和正文关键词；有结果、无结果、清除、Escape 关闭、焦点返回。
- 筛选：关键词和类别组合通过原生 GET 表单写入 URL，刷新和分享可复现本轮筛选。
- 目录：桌面侧边、窄屏 details；窄屏点目录项后收起，锚点保留顶部空间。
- 复制：从代码节点取得纯文字，反馈成功或失败，不把行号或按钮文本写入剪贴板。
- 图片：只用独立生成照片作为样本，放大弹层可关闭，关闭恢复原按钮焦点。
- 菜单/弹层：原生模态层，背景不能操作；关闭解锁页面滚动，快速开关时不把旧焦点移入新弹层。
- 动效：弹层约160ms短淡入和轻位移，链接/按钮约160ms状态过渡；减少动态效果时直接切换。
- 页面跳转保持原生导航，不强行添加过场。更丰富的关闭动画、触摸细节与实机性能留待状态评审后验证。

## 5. 本轮视觉修正

1. 手机技术长标题出现单字尾行，针对样本设置合理换行；正式内容仍需要通用标题策略，不能给所有文档硬编码断行。
2. 原固定 SVG 的中文标签在手机上过小，改为原生文字网格，并为紧凑桌面增加两行布局。
3. 目录同时使用 scroll padding 和 scroll margin 导致定位过低，收敛为标题自身的定位间距。
4. 模态层关闭后的滚动锁与异步焦点恢复存在时序问题，统一同步关闭处理，并避免旧弹层影响新弹层。

## 6. 当前边界与下一步

本轮是模块稿，未接入真实 Markdown 解析、登录、私密附件、生产搜索、内容维护与发布链路。没有宣称正式产品的18项验收已完成。

独立菜谱照片原始 PNG 约2.86MB，目前用于本地版式。尚未做生产级多尺寸压缩与加载预算验证，不能把本轮本地速度当线上性能成绩。

优先评审：首页信息密度与手写位置、技术页标题/正文/目录、菜谱材料与步骤、手机导航。之后收敛模块，再进入正式渲染、资源优化和权限技术设计。
