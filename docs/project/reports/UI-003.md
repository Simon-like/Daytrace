# UI-003：跨端焦点与移动搜索键盘

日期：2026-11-03。范围：桌面与独立 H5 的点击焦点反馈，以及 H5 搜索键盘语义。

## 结果

共享控件和两端全局焦点改为统一鼠尾草绿；搜索输入框与容器只保留一层轻量反馈。H5 搜索声明 `enterKeyHint="search"`，提交后失焦，清除后恢复输入焦点。

截图中的“上一个／下一个／完成”三个图标属于 iOS Safari 原生表单辅助栏，不是应用组件。网页无法通过 HTML／CSS 可靠关闭，本任务没有伪造移除结果。

## 验证

- lint：159 文件，0 问题。
- typecheck：API、桌面、H5 通过。
- Chromium 专项：2／2，通过桌面焦点环、H5 单层光晕、搜索提交失焦和清除重聚焦检查；脚本错误 0。
- 证据：[浏览器结果](../evidence/UI-003/browser-results.json)、[桌面截图](../evidence/UI-003/search-focus-1440.png)、[H5 截图](../evidence/UI-003/search-focus-390.png)。

## 限制

Chromium 移动视口不等于真实 iPhone；Safari 原生辅助栏和键盘收起效果仍需真机复核。本报告不改变 UI-002 性能阻塞、完整 AC／NFR 或发布状态。
