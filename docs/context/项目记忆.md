# 稳定项目共识

更新：2026-11-02。这里只存长期共识和源文档位置；当前工作、测试数量和上线状态看各自权威来源。

## 产品

有迹 · Daytrace是个人知识与生活站点，沉淀技术实践、生活经验和随想认知。重点是以后能找回理解的过程、看到自己的变化，不只生成通用百科。

一期展示与阅读优先，尤其iPhone网页的审美、中文排版、响应式和流畅；Markdown为主要流通物，正文与附件可迁移。允许不完整记录与以后补充。站内编辑器、原生App、复杂Agent和社交平台不在一期。

公开与私密共存，正文、图片、摘要、索引、缓存和错误都要有真实访问边界；前端隐藏不构成保护。教程、用户真实经历和AI补充有明确区分。

## 设计与技术

D/D²私人档案方向：深橄榄、矿物纸白、精修排版，必须保留有限手写注记，避免E的大面积撞色。品牌为“有迹 · Daytrace”；旧原型暂名不批量改写历史。

用户已确认Next.js（React）+ NestJS + monorepo。实施采用TypeScript与pnpm workspace；Next展示和服务端适配，Nest内容/业务/权限，不建设两套权威接口。具体版本以工程配置为准，架构取舍以ADR为准。

## 协作与管理

用户主要使用Kimi和Codex，项目只有一套AGENTS入口、docs文档体系和中央任务队列。独立分支/worktree交付，共享配置由集成者串行处理。用户希望看筛选后的结果、实际设计和证据，避免冗长工具清单和虚假完成百分比。

文档在docs；代码、素材、可执行运维和实验留原目录；站点Markdown是产品数据，不能混入项目文档或自动发布docs。真实私密与凭据不进普通Git，忽略不等于已备份。
