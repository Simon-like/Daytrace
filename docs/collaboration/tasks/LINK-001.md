# LINK-001：记录关联与跨次菜谱实践对照

## 目标

在不改变稳定记录 ID 和现有 Markdown 正文的前提下，增加显式人工关联，让技术记录互链、随想保留来源，菜谱能够对照多次实践。关联目标只在调用方本来就有权阅读时出现。

## 交付与验收

- `relatedRecords` 是可选的稳定 ID 数组；重复、自关联和不存在目标使整份候选快照失败，不静默丢弃错误。
- 公开详情只包含公开已发布关联；主人详情可包含其有权读取的私密、草稿和归档关联。公开响应、索引与分享数据不得泄露私密目标。
- 桌面与 H5 展示关联记录；菜谱关联按实际发生日期形成对照入口，空日期不伪造。
- 内容导入、更新与导出保留关联字段；公开／主人 API、双端浏览器和权限负例有实际证据。

## 边界与交接

owner 为 `kimi-LINK-001-relations`，只在 `dev` 串行集成，不新建任务分支、不合并 `main`、不部署。复用 F2 内容维护和 F1 权限链路，不另建知识图谱、自动推荐或站内编辑器。每个独立功能边界验证后提交并推送。
