# 统一设计系统与独立 H5 实施计划

日期：2026-11-03。任务：SYSTEM-001 → MOBILE-001。执行方式：当前会话按顺序施工，不使用子 Agent，不自动 commit／push。

## 目标与边界

保留用户已认可的纸张、档案绿、页片符号、检索台和分层按钮，不再重开主题。桌面端解决跨页面不一致和缺少入场编排；移动端建立独立 `apps/h5`，而不是继续通过媒体查询压缩桌面。Nest 仍是唯一业务与权限接口，正文不等动画，不新增动画库，不借本轮掩盖 Select 性能或正文脚本预算缺口。

## 设计方案

### 共享语言

- 色彩：纸面 `#f4f4ed`、浅纸 `#fafaf6`、档案绿 `#243128`、正文墨 `#202720`、辅助墨 `#667065`、修订色 `#93634f`。色彩只承担纸面、层级和状态，不增加渐变装饰。
- 字体：宋体角色用于记录标题和页面题名；系统中文黑体用于正文与操作；等宽字体用于日期、索引和检索提示；手写只保留有限的个人注记。
- 形状：14–20px 的控件与面板圆角、3px 主按钮承托、圆形箭头／勾选、档案页片符号。签名元素是“检索台＋页片索引”，不再添加另一套视觉符号。
- 桌面：224px 稳定档案侧栏，主内容保持阅读宽度；页面题名、说明、操作区使用共同节奏，记录元数据使用同一排版。
- H5：紧凑顶部品牌、内容优先的单列和 4 项底部主导航。归档筛选进入底部面板，搜索独占首屏操作区，正文不被桌面侧栏和三栏卡片挤压。

### 入场编排

品牌与导航稳定，页面题名／操作区作为少量分组以 `opacity + translateX/Y(≤12px)` 在 200–280ms 内完成，组间仅短延迟。正文与记录列表不等待、不逐项 stagger。CSS 动画不依赖 JS 才显示内容；减少动态效果时全部即时可见。

## 假设

- 首版通过明确 `/h5/` 入口体验，不根据 UA 自动跳转。
- H5 使用与桌面相同的 Next.js、React 和 Tailwind 版本，避免增加框架和运行时。
- 共享包直接导出 TypeScript 源，由两个 Next 应用通过 `transpilePackages` 转译；Tailwind 显式扫描共享源。
- 原有桌面路由、API、Markdown 语义和演示权限行为保持不变。
- 本轮的 Chromium 移动视口与触摸模拟不是 iPhone／Safari 真机验收。

## 实施步骤

1. **共享设计包**
   - 新建 `packages/ui`，导出 tokens、Icon、BrandMark、Button、Input、Select、Checkbox。
   - 将第二轮控件实现迁入共享包，桌面原路径保留 re-export；明确 client 边界和样式引用。
   - 两个应用使用相同的 CSS 变量、字体和动效 token，Tailwind 扫描共享包。

2. **共享内容包**
   - 新建 `packages/content`，承接公开内容服务端 API、搜索 contract／state／request 和归档 discovery state／request。
   - 桌面旧模块改为兼容导出；不复制接口，不改变公开／私密边界。
   - 保持现有单元测试和请求取消、筛选恢复行为。

3. **桌面统一与入场（SYSTEM-001）**
   - 统一页面 heading、topline、操作区、记录卡片、主／次按钮、标签、空状态和表单控件。
   - 清理移动端旧汉堡菜单的职责，为独立 H5 留出明确入口；桌面自身仍保留既有响应式回退直至 H5 验收。
   - 为标题与操作区增加短分组入场，正文和列表静态可读。
   - 更新视觉／动效基线，说明最新要求对“默认无全页转场”的补充，而不是引入全页动画。
   - 构建、类型、lint、单元／集成、18 流程与 56 视口回归，保存桌面证据。

4. **独立 H5（MOBILE-001）**
   - SYSTEM-001 交付后新建 `apps/h5`，设置 `basePath: "/h5"`，建立独立 root layout 和移动 shell。
   - 首页：品牌／当期记录优先，分类入口改为短索引，不做桌面三栏的缩小版。
   - 归档：已选条件摘要＋底部筛选面板，支持 Escape、焦点返回、背景滚动锁定与快速重复操作。
   - 搜索：独立检索台、建议词、结果状态与取消请求；阅读：17–18px 正文、局部横滑和现有图片增强。
   - 主站 rewrites 将 `/h5/:path*` 代理到独立 H5 服务；静态资源使用 basePath，API 仍走 `/api/v1`。
   - `run-dev.mjs` 同时启动 API、桌面和 H5，验证端口转发和退出清理。

5. **双端验收与交付**
   - 分别构建桌面和 H5；执行原桌面回归和新增 H5 导航、筛选、搜索、阅读、返回、减少动态效果测试。
   - 检查 320、390、430、768、1440，实际查看首页／归档／搜索／阅读截图。
   - 检查无整页横溢出、触摸目标、焦点、safe-area、资源路径和 page error。
   - 记录未闭环的 Select 4× CPU 长事件、正文 gzip 预算和真机边界，不标生产验收。
   - 停止临时 Node／Next 服务，交付可重启预览和任务证据。

## 完成定义

共享组件与内容能力实际被桌面和 H5 使用；桌面不再各自发明控件样式；H5 有独立 shell 和移动交互；测试和截图支持上述结论。文档结构通过不代表视觉或真机通过，任务状态只写中央 board。
