## 后续开发基准

- 查看开发成果、开始新工作统一使用最新`dev`：`git switch dev && git pull origin dev`。功能、修复、文档与证据都先提交并推送`dev`。
- `main`只通过用户或集成者明确执行的`dev → main`合并更新；合并不等于部署、真机或正式QA通过。既有`agent/*`分支只作历史记录，不自动删除，也不作为后续入口。
- 工程以根配置为准：Node.js 24.18.0、pnpm 11.23.0；Next.js 16.4.3、NestJS 12.3.2、React 19.3.1。安装使用`pnpm install --frozen-lockfile`，快捷启动见[本地开发手册](../development/local-dev.md)和[Demo手册](../development/demo.md)。
- Next.js + NestJS + TypeScript + pnpm workspace不再重开选型。桌面为`apps/site`，独立移动端为`apps/h5`，共享`@daytrace/ui`与`@daytrace/content`，继续使用既有Nest API。
- H5首版明确入口为`/h5/`，不做未经验证的UA自动跳转。当前仍是合成数据本地Demo，不是正式生产版本。
