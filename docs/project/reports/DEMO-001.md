## 3. 实测修复

1. 搜索建议切换同一路由时保留旧组件状态：按查询重新挂载搜索面板；归档也区分查询，避免同路径切换不更新。
2. 登录使用Next Link客户端导航后会话已建立、界面仍取旧主人页缓存：身份跳转改为真实链接导航；注销用完整页面替换，BFCache恢复时重新验证。
3. 原生dialog的close事件晚于可见状态更新：移动菜单在关闭/取消时同步恢复滚动与焦点，避免关了菜单仍锁住页面。
4. 附件原声明宽高未写入HTML：清洗后的img使用已验证元数据预留空间，减少加载后挤动正文。
5. 公开contentRevision原含私密源变化：改为公开投影单独修订，不让私密更新改变公开游标/缓存版本；私密校验错误移除源路径。

未删除失败断言或放宽隐私/布局条件来获得通过；首轮失败日志和截图留在本机.local诊断区，正式证据是修复后的回归。
