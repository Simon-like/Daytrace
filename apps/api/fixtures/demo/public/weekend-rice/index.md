本篇为无照片菜谱演示，说明记录不必等素材齐全才开始。

## 材料

一人份：大米一小杯、喜欢的菌菇一把、胡萝卜少量。调味使用生抽和盐，按口味少量调整。

## 步骤

1. 大米洗净，按平时煮饭的比例准备水。
2. 菌菇与胡萝卜切成容易入口的大小，先简单炒香。
3. 将食材铺在米上，按电饭锅正常程序煮熟。
4. 焖好后再拌匀，尝味后补调味。

## 注意事项

菌菇本身会出水，第一次尝试时先少放一点水，根据米与锅的情况调整。下次记录实际口感，比抄下一个看似精确的数字更有用。
