# 项目进度

更新：2026-11-03。**统一桌面与独立 H5 本地 Demo 已可预览，尚未集成主分支或生产发布。** 研发已推进到 M3 演示闭环／M4 本地预检；这是执行进度，不表示所有阶段的正式退出门槛均已通过。

## 已有成果

- 产品：PRD、18 组 AC 与 NFR 矩阵、阶段路线图、文档／知识分层与协作队列。
- 设计：D／D² 私人档案、必须保留的手写；“有迹 · Daytrace”品牌与醒目图标，历史原型保留。
- 工程：Next.js + NestJS + TypeScript + pnpm workspace，共享 `@daytrace/ui` 与 `@daytrace/content`，桌面 `apps/site` 与独立移动 `apps/h5` 复用同一 Nest API。
- 内容与权限：可迁移 Markdown、完整正文渲染、公开投影、主人会话与附件隔离，示例含 8 篇公开、1 篇私密、1 篇草稿，全部为合成内容。
- 桌面体验：统一纸张／档案绿、控件和短分组入场；首页／分类／归档筛选与返回、公开搜索、三类阅读／目录／复制／图片、关于／404、演示主人登录／退出。
- 移动体验：独立首页优先级、四项底部导航、底部筛选面板、移动检索台和 17px 长文阅读；支持 safe-area、局部代码／表格横滑、图片灯箱与减少动态效果。
- 验证：桌面 Chromium 19 条用户路径、56 视口通过；H5 5 组交互、24 视口通过；单元 43、HTTP 集成 8＋13＋5，页面脚本错误 0。

## 后续开发基准

- 2026-11-02 同步时，`main` 与 `origin/main` 均为 `1079863`。该 SHA 只作历史对照；每个新任务从届时最新主分支切独立分支／worktree，集成前重放最新变化。
- 工程锁定 Node.js 24.18.0、pnpm 11.23.0，正式依赖基线为 Next.js 16.4.3、NestJS 12.3.2、React 19.3.1；以根 `.nvmrc`、`.node-version`、`package.json` 和应用 manifest 为准。
- 保持 Next.js + NestJS + TypeScript + pnpm workspace 及现有内容／权限边界。移动端可以拥有独立页面和交互，但不复制第二套业务 API；共享控件能力以可选、向后兼容的方式演进。
- 所有新工作先由协调者建立任务卡并认领；共享路由、契约、依赖与锁文件由集成者串行处理。文档完成、模块 done、本地 Demo、正式 QA 和生产发布是不同门槛。
