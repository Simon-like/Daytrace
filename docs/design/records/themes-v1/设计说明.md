## 提示词要点

统一生成高保真中文个人知识与生活站点设计稿，横向 3:2，一张图左侧为桌面首页，右侧为同一套主题的手机技术文章页。技术实践、麻婆豆腐、个人感想使用相同题材。页面包含过去的认识、后来的补充与给自己的提醒。风格温暖、安静、有人的气息，避免营销落地页和仪表盘结构。手机正文要求舒适字号、目录入口、清晰代码区与复制入口。

- A 青苔手记：雾白、深绿、苔绿、枯叶色；左侧日期轨迹、中央记录流、右侧自我提醒；宋体标题与清晰正文搭配，时间与认知变化为识别点。
- B 日常来信：燕麦白、深棕、低饱和酒红、杏仁色；居中刊头、书信式阅读、图文与边注组合；温暖文学感，避免邮票、信封、撕纸等装饰。
- C 晴日散步：瓷白、蓝灰、浅黄、淡鼠尾草色；非居中刊头，开场文字与日常照片配对，下方图文杂志式编排与短感想；轻盈自然，避免贴纸和大面积渐变。

选择后应先转化为可运行的手机文章页，验证中文混排、长代码、宽表格、图片加载、目录和浏览器返回，再展开整站。
