# 从静态稿到响应式页面的四个发现

适用范围：MODULES-001、Chromium模拟视口。以下是这次原型观察，不代表所有浏览器与内容都已验证。

1. 固定SVG viewBox会把图中文字一起缩小。流程标签改为原生HTML网格，窄桌面重排，比单纯缩放更容易保住字号。
2. 顶部scroll padding与标题scroll margin叠加，会让锚点落得过低。先只保留一层清楚的定位规则，再验证真实固定导航高度。
3. 模态层关闭事件与焦点恢复可能异步，旧弹层不应抢走新弹层焦点。关闭时统一解锁/恢复，且先检查是否还有其他打开的模态层。
4. 非空search input可能先消费Escape清空输入，导致对话框不关闭。原型显式定义模态层的Escape行为，并补上带搜索词的回归。

这些方法都服务阅读与可用性，不是为了增加效果。正式内容接入后还需验证任意长标题、复杂图解和真实Safari环境。
