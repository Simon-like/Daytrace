# 站点个人内容库

这里存放产品未来展示的个人记录，与项目需求/报告、研发知识分开。

| 路径 | 用途 | 约束 |
| --- | --- | --- |
| public/engineering/ | 明确可公开的技术实践 | 每条记录单独目录，Markdown与附件相对引用 |
| public/life/ | 明确可公开的生活/菜谱 | 不以生成照片或教程做法冒充个人实践 |
| public/reflection/ | 明确可公开的随想 | 允许短记与带日期补充 |
| private/ | 主人记录的本地存储边界 | 默认Git忽略；未来单独部署/备份，不进入公开构建 |
| fixtures/ | 技术验证的合成测试内容 | 不能当真实个人内容发布 |

当前尚无正式内容协议与解析器，不把README或.gitkeep误当文章。内容字段、状态、来源、迁移校验由CONTENT-001锁定，当前不复制整套原型样本到公开目录。

私密目录的Git忽略只是防误提交，不是网站访问控制或备份方案。生产读取路径、附件、索引、缓存与认证仍须在SECURITY-001中验证。公开内容是显式发布结果，不能由AI根据“看起来不敏感”自动移入public。

模板在 `docs/templates/content/`，技术契约确认前只作整理草稿。给站点新增内容不需要修改项目PRD，给项目写复盘不应进入此公开内容库。
