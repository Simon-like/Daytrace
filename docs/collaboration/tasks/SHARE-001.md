# SHARE-001：公开分享与双端阅读偏好

## 目标

补齐 F4：让公开记录可被订阅、发现并以一致的规范地址分享，同时让桌面与 H5 读者能够选择并恢复舒适的正文字号。所有公开聚合与分享数据继续复用现有公开 API 权限投影。

## 交付与验收

- RSS 2.0 与 sitemap 沿公开游标读取全部公开已发布记录，不只取首页；XML 正确转义，主人页、H5 别名、私密与草稿内容不得进入公开聚合。
- 桌面和 H5 公开详情提供一致的 canonical、Open Graph 与 Twitter 元数据；规范链接统一为桌面 `/records/<id>/`。
- 分享卡由本地服务端生成 1200×630 PNG，支持中文；未知、私密或草稿记录只返回通用品牌卡，不泄露记录标题或存在性。
- 桌面与 H5 提供标准／较大／特大三档正文偏好；同源 localStorage 恢复、非法值回退、键盘与读屏状态清晰，不改变主人权限或减少动态效果。
- 相关单元／集成／双端浏览器、lint、typecheck、build 与文档检查有真实证据；读取最新功能提交的托管 CI 结果。

## 边界与交接

owner 为 `kimi-F4-001-sharing`，只在 `dev` 串行集成，不新建任务分支、不合并 `main`、不部署。暗色模式、自动社交推荐、第三方图片运行时、真实社交爬虫与生产发布验收不在本任务内。真实 iPhone/Safari、性能预算、QA-001 与 RELEASE-001 保持独立门槛。
