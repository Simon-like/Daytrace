# UI-003：跨端焦点样式与移动搜索键盘语义

用户在桌面与独立 H5 点击控件时发现过重的黑色焦点框；真实 iPhone 搜索截图同时出现双层描边与 iOS 键盘表单辅助栏。

## 范围

- 统一共享 Button、Input、Select、Checkbox 与两端全局链接的轻量焦点样式，保留键盘导航的可见焦点。
- 搜索容器使用单层浅鼠尾草色光晕，移除输入框与容器叠加的双层描边。
- 为 H5 搜索声明搜索回车键语义，提交后收起键盘；不伪造可关闭 iOS 原生辅助栏的能力。
- 保存桌面与移动视口回归证据；真实 iPhone 辅助栏仍需真机复核。

## 基线与写入

基于最新 `dev`，不新建任务分支。只修改共享 UI、两端焦点与搜索样式、H5 搜索交互、相关测试和交付文档，不改 API、内容、权限、依赖或生产配置。保留主工作区已有 Next 自动文件、ARCH 证据与品牌素材现场。

## 验收

- 鼠标／触摸点击不产生突兀的双层黑框；键盘 Tab 仍有清晰可见的焦点指示。
- 桌面与 H5 搜索焦点只呈现一层轻量品牌色反馈，不改变布局尺寸。
- H5 搜索声明 `enterKeyHint="search"`，提交后输入框失焦；清空后仍可继续输入。
- lint、typecheck 与相关浏览器回归通过，明确区分 Chromium 仿真与真实 iPhone 结果。
