# 灵动检索控件调研

查阅日期：2026-11-02
任务：UI-002 第二轮。用户认为首轮按钮、搜索框和下拉框变化不足、样式普通，要求增加网上调研。

## 参考与可迁移原则

- [Raycast macOS 7 更新](https://www.raycast.com/changelog/macos/7)：官方明确使用更大的搜索栏体现主任务，并用定制图标和上下文操作条建立产品感。迁移为 Daytrace 的一体化检索台，而非输入框旁再摆一个普通按钮。
- [Linear：Invisible details](https://linear.app/blog/invisible-details)：操作应让用户感觉直接，键盘与指针反馈需要连贯。迁移为 Enter 提示、清晰 focus、保留 Select 键盘选择，不用动画阻碍操作。
- [Codrops：CSS Button Hover Animations](https://tympanus.net/codrops/2021/02/17/ideas-for-css-button-hover-animations/)：按钮可通过形状和内部元素形变产生个性，clip 不应裁切焦点。迁移为独立圆形箭头和底部承托，焦点仍留在控件外轮廓。
- [Codrops：Magnetic Buttons](https://tympanus.net/codrops/2020/08/05/magnetic-buttons/)：内部层与阴影以不同方式响应能产生触感。只采用“分层反馈”，不加入追踪鼠标的 JS 磁吸，避免阅读产品过度炫技。
- [Webflow：Microinteraction examples](https://webflow.com/blog/microinteractions)：动效应快速、目的明确、风格一致并尊重减少动态效果。用于约束本轮只做 120–200ms 的局部位移、按压和图标反馈。
- Dribbble 实际查看了 [UI Components / Light Part](https://dribbble.com/search/voice-input-animation)、[Multi-Select Filters for Data Tables](https://dribbble.com/search/multi-select-form) 的控件参考图。前者启发图标独立色块，后者仅用于确认选中态和分组；没有照搬其高饱和绿色或后台表单布局。

## Daytrace 自己的方案

签名元素是“活页检索台”：暖白承托面、档案绿主按钮、独立搜索符号、底部纸层和 Enter 键提示组成一个完整操作面。Select 使用页片符号，让“记录／档案”成为控件语义，而不是通用后台的灰色输入框。

色彩保持纸张 `#f4f4ed`、承托白 `#fffef8`、主按钮 `#31503d`、索引底 `#e9ede4`、图标底 `#d7e0d1`、正文 `#202720`。宋体只负责页面标题，控件继续使用系统无衬线，键提示使用等宽字体。

动效仅用于“找到—按下—展开”三条因果链：focus 浮起、按钮箭头滑动与按压、选项短距离横移。不采用粒子、磁吸、循环呼吸或全页动画。
