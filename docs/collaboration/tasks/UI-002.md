# UI-002：控件质感、归档节奏与方向性动效优化

用户在检查 READER-002 页面后，仍不满意按钮、搜索框、下拉框，指出归档分割线间距问题，并希望增加淡入淡出与左右滑动效果。

## 范围

- 重塑本地 Button、Input、Select 的视觉层级、圆角、边框、图标与焦点状态，保持无头组件与键盘契约。
- 修正归档筛选与记录列表的分割线、上下留白和内容节奏，避免连续线条造成拥挤。
- 在筛选结果、搜索结果和标签展开中使用单容器透明度与 4–8px 左右位移；不逐项 stagger，不做正文／路由全页动画。
- 复用动效 token，支持减少动态效果，保存桌面／移动截图和浏览器回归证据。

## 基线与写入

依赖 READER-002。新 worktree 从最新主分支创建，以补丁带入 UI-001、MOTION-001、MOTION-002、READER-002 的未集成交付，不覆盖原工作区。只修改任务允许的本地组件、归档／搜索样式与交互、验收测试和交付文档，不改 API、内容、权限、依赖或生产配置。

## 验收

- 三类控件在默认、hover、focus、disabled、打开和选择状态下风格一致，无浏览器原生异常描边。
- 归档分割线与内容间距在 320–1440 视口下均衡，无整页横溢出。
- 方向性动效可中断，不逐条延迟，不改变布局尺寸，减少动态效果时即时可读。
- lint、typecheck、unit、integration、build 和浏览器验收通过，提供可重启的本地预览。
