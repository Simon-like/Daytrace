# 有迹 · Daytrace

日期：2026-10-30。状态：本轮命名与Logo提案，等待用户反馈；不代表用户已确认最终品牌。

## 命名

中文：**有迹**。英文：**Daytrace**（Day + Trace，每一天留下的痕迹；是意译式品牌名，不是“有迹”的逐字翻译）。一句话：**让经历有迹可循。**

既容纳工作中的问题拆解，也容纳一道菜、一次感想。重点是日后能找回自己的理解与变化。原型中的“日常有迹”为历史暂名，本轮不批量改写旧设计或旧报告。

## 标志

一个开放的档案边角、一笔小写y（“有”的拼音首字母）、一枚记录点，共三个图形元素。边角对应归档与秩序；y的弧线对应个人手写痕迹；点对应每次细小积累。无渐变、阴影或外部图片。

- 深橄榄：`#29352C`。
- 矿物纸白：`#F0F0E8`。
- 横向标志用于标题/页首；小尺寸使用独立图标，不缩小整组中文字标。
- 浅底使用深色版；深底使用reverse反白版。
- 独立图标建议至少24 CSS px，16px仅为极限favicon观察样本；实际浏览器呈现待实现时验证。
- 图形周边留白至少约一个记录圆点直径，避免贴边和叠加装饰。

## 文件

- `logo.svg` / `logo.png`：中文与英文组合，PNG宽1600px，透明底。
- `logo-icon.svg` / `logo-icon.png`：独立图形，PNG为1024×1024，透明底。
- `logo-reverse.svg`、`logo-icon-reverse.svg`及对应PNG：反白版，透明底。
- `icon-16.png`、`icon-32.png`、`icon-64.png`、`icon-180.png`：透明图标。

SVG是可编辑源文件，不依赖本工具。中文字标使用系统宋体回退、英文使用系统无衬线回退；SVG文字未转曲，异机字体可能不同。PNG是本次确定的渲染外观。使用的字体文件未嵌入或分发。
