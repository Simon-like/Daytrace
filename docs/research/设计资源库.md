# 个人站点设计资源库

调研日期：2026-10-30。版本：首轮候选集，24 项资源。

适用项目：以 Markdown 为内容底座，容纳技术实践、生活照片与个人感想；温暖、安静的生活手记方向；重点保障 iPhone 网页长文阅读，同时支持桌面与公开、私密内容。

核验方式：Exa 搜索与官方页面/源仓库阅读，并查询当前应用的插件目录。以下能力是资料核验，不是本项目实测成绩。没有安装新 Skill、MCP 或应用，没有订阅付费服务。

## 推荐组合与验证顺序

### 低接入成本，先获得更丰富的参考

Minimal Gallery + Siteinspire + Landbook → 挑 3–5 个具体案例 → 已有 Figma 能力整理参考板 → 现有前端指导实现 → 指南评审和浏览器验证。

### 希望有不同工具提供设计备选

保留真实作品参考，Stitch 和 Pencil/pen.dev 中先选一个试用。用同一组中文内容生成至少三个不同方向，再由用户选定；需要时引入 v0 作额外对照。多个生成工具也可能产生相似结果，因此必须给明确的参考与反例。

### 设计定下以后保障手机质量

Impeccable 的评审/排版/适配指导 + Vercel 指南 → 浏览器多尺寸检查 → 真实 iPhone Safari 阅读和交互验证。若多视口比较频繁，再考虑 Polypane。

MCP 是工具连接方式，Skill 是工作指导；增加两者数量本身不保证视觉多样性。真正增加选择的是：不同来源的真实案例、明确不同的设计方向、独立生成结果，以及同一内容下的比较。
