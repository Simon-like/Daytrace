# ADR-0002：技术路线候选

- 日期：2026-10-30。
- 状态：proposed。
- 推荐：Astro + TypeScript + 原生CSS/有限局部交互；公开预渲染，私密按需授权读取。Node为优先验证运行目标，实际部署前提另核。
- 证据来源与比较：[技术选型与研发路径](../技术选型与研发路径.md)。

## 尚未作出的决定

具体版本、包管理、正式渲染/搜索/会话库、部署提供商、真实私密数据源与默认发布策略。没有为本ADR安装依赖或生成apps/site脚手架。

## 改为accepted的门槛

ARCH-001、CONTENT-001、SECURITY-001完成，并记录相同样本的渲染、资源、迁移、运行时和访问隔离结果。集成者说明为何保留首选或切换备选，锁定版本与依赖，列出仍需用户决定的成本/账户事项。

重审触发：运行宿主不支持预期数据路径、私密隔离无法满足、手机预算不满足且无法合理修正、用户明确要求另一生态、未来站内交互成为主需求。不能因为Agent个人偏好反复换框架。
