# CONTENT-004 内容库会话失效与预览恢复

共享内容管理客户端对 401 广播会话失效并推进代次；内容库清除私密列表、预览、编辑和筛选，提供当前端的重新登录入口，旧代次的成功或网络失败响应不能覆盖失效状态。预览恢复遇到网络／服务错误保留会话存储标识并提示；会话存储不可用时仍可继续当前预览和操作。

Nest 仅在可访问的导入根目录下确认批次目录不存在时返回 `IMPORT_NOT_FOUND` / 404；编号无效、清单缺失／损坏或存储根不可访问不会伪装成不存在。前端只在确认 404 或用户完成操作时移除恢复标识，不删除服务器预览。
