# 阅读型界面与无头组件调研

日期：2026-11-02。任务：UI-001。用途：把用户截图反馈转成可执行的界面与组件决策；不是通用“极简风”素材堆叠。

## 1. 从实际界面出发

用户截图暴露的是结构问题而非单纯配色问题：首页同时出现侧栏分类、三张分类卡、最近记录、厨房和随想，多个模块争夺第一注意力；归档默认展开所有标签，筛选比结果更显眼；原生select、checkbox与搜索框的双层/异常焦点破坏一致性；正文页出现标题裁切和正文列过窄。

本轮只采用能直接解决这些问题的方案。Markdown解析与正文组件不在调研后立刻重写，先稳定shell、编排和控件。

## 2. 阅读与档案界面参考

| 来源 | 观察 | 本轮采用 | 不照搬 |
| --- | --- | --- | --- |
| [HubSpot：Manuel Moreale等简洁站点案例](https://blog.hubspot.com/website/simple-website-examples) | 个人博客可用排版、时间顺序与少量强调建立焦点；每屏一个主意 | 首页以最近记录为主体，日期成为归档索引；减少装饰和竞争链接 | 不改成完全无图的纯文本博客，不复制黄色链接 |
| [Jason Heppler：A New Design for Readability](https://jasonheppler.org/2026/03/02/a-new-design-for-readability/) | 阅读重构强调内容优先、简单导航、有限字族/颜色、清理旧CSS | 删除首页次级栏目与重复导航；保持宋/黑/等宽加有限手写；新增样式集中治理 | 不隐藏所有桌面导航，不追求其碳排或快捷键方案 |
| [Tubik：编辑型网页案例](https://blog.tubikstudio.com/media-editorial-website-design/) | 受控色彩、清晰层级、稳定正文节奏比装饰更重要 | 用纸白、墨色和结构线建立节奏，图片只在有内容职责时出现 | 不做大图杂志首屏，不增加沉浸式动效 |

结论：Daytrace的“简”应是少做选择，而不是把大量小号文字和细线排满。保留私人档案的深橄榄侧栏与一处手写注记，其余让位给记录本身。

## 3. 组件与工程参考

- [Tailwind CSS v4官方说明](https://tailwindcss.com/blog/tailwindcss-v4#css-first-configuration)：使用`tailwindcss`与`@tailwindcss/postcss`，CSS中`@import "tailwindcss"`，以CSS变量和`@theme`维护令牌，不增加旧式JS配置。
- [Radix Select官方文档](https://www.radix-ui.com/primitives/docs/components/select)：无样式、受控/非受控、焦点管理、完整键盘导航与typeahead；本地封装Trigger/Content/Item，使用`position="popper"`与触发器宽度变量。
- [Radix Checkbox官方文档](https://www.radix-ui.com/primitives/docs/components/checkbox)：本地控制checked/disabled样式，保留Space键盘行为与表单输入。
- [Ariakit Tailwind包说明](https://www.npmjs.com/package/@ariakit/tailwind)：其Tailwind插件仍标为experimental，本轮不把它作为基础依赖。

选择Tailwind CSS v4 + 按需Radix Primitives，本地源码维护组件样式。不是引入一套带默认皮肤的UI库，也不复制整站shadcn模板。Button/Input使用原生语义，Select/Checkbox使用无头行为；后续Dialog等组件只有在迁移到对应页面时才增加依赖。

## 4. 第一轮界面结构

```text
桌面首页                         手机首页
├─ 精简档案侧栏                  ├─ 品牌 + 搜索 + 菜单
├─ 一句主题 + 一处手写注          ├─ 一句主题
├─ 三类文字索引（数量）           ├─ 三类文字索引（横向换行）
├─ 最近记录：日期 / 标题 / 摘要    └─ 最近记录：日期在上，标题在下
└─ 极简页脚

归档：标题与数量 → 类别Select + 标签展开按钮 → 记录结果
搜索：明确标签 → 单一输入框 + 搜索按钮 → 状态/结果
```

签名元素是“时间索引”：日期不是装饰性编号，而是记录真实的时间关系。桌面形成稳定的左日期右标题阅读节奏，手机自然换行，不靠卡片包围每条记录。

## 5. 仍需实测

Tailwind与Radix会增加多少客户端脚本、Select在窄屏和键盘下是否正确、既有筛选/搜索返回状态是否保持，都必须以构建和真实Chromium结果为准。调研本身不构成视觉、性能、真机或可访问性验收。
