# 模块接线与浏览器验收

适用：Next App Router + Nest分模块协作；以下来自真实本机Demo验证，不代表Safari或生产提供商行为。

1. 各模块都能构建，仍可能没有注册到AppModule/共享路由。接手时先找“用户从哪里能打开它”，再统计代码数量或测试数。
2. 身份跳转不要当普通内容页使用客户端Link。实测会话已经建立后，主人页面仍保留旧未登录状态；完整链接导航能让服务器重新判断。Cookie存在不等于界面刷新，更不等于鉴权正确。
3. searchParams变化与客户端组件内部状态是两层。示例搜索建议切换后，URL已更新而旧结果仍在；要明确同步或以查询作为组件key。
4. dialog可见性先变化、close事件后触发。关闭按钮/Escape/跳转三个出口都验证滚动锁和焦点，不能只看弹层消失。
5. 隐私不只有正文：附件、源文件路径、公开修订/游标、索引、RSC和退出后历史状态也有独立出口。
6. 新框架性能预算要实测，不能用功能测试绿灯替代。当前Next文章脚本超过原80 KiB，记录差距并保留发布前待办。
