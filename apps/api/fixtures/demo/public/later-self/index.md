## 现在的理解

比起很快站在一个明确的立场上，我更想知道：这个看法来自哪些经历，又遗漏了哪些视角？

## 可以改变

> 记录当时的自己，不等于要求未来的自己永远同意。

保留日期，保留问题，保留重新思考的空间。回看的价值，也许正是在这里。
