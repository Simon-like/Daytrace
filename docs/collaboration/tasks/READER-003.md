# READER-003：文章目录滚动定位

用户指出桌面文章页右侧目录不能随页面滚动实时定位。CONTENT-003 已统一正文与目录 AST，本任务只修复阅读位置反馈，不重写渲染管线。

## 范围

- 用确定性的标题位置计算替换窄观察带 IntersectionObserver，滚动时通过单个 `requestAnimationFrame` 合并更新。
- 向上／向下滚动均选择当前阅读小节；首屏保留首项，页底明确选择最后一项。
- 点击目录、hash 变化和减少动态效果行为保持可用；不接管原生滚动，不修改 Markdown 标题 ID。
- 添加位置计算单测与桌面浏览器滚动回归，保存证据并独立提交 `dev`。

## 基线与写入

基于同步 Codex CONTENT-003 后的最新 `dev`（`0465550`）。只修改桌面 reader、相关测试和本任务文档，不改 API、内容契约、H5、依赖或生产配置；保留既有本地现场。

## 验收

- 目录高亮随向下和向上滚动更新到正确标题，不停留在首次点击项。
- 页面底部最后目录项为 `aria-current="location"`；快速滚动每帧最多计算一次。
- 目录点击、hash 定位与键盘行为不回归；lint、typecheck、相关单测和浏览器检查通过。
- Chromium 结果不冒充真实 Safari／iPhone 验收。
