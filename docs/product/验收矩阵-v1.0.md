## 2. 非功能专项

| 编号 | 场景 | 检查内容 | 通过条件 |
| --- | --- | --- | --- |
| NFR-01 | 首次文章加载/缓存后访问 | 必要 JS、字体、图片、传输体积和正文出现路径 | 满足 PRD 预算或有明确测量和经评审的例外；正文不等解析器下载 |
| NFR-02 | 图片晚到、字体回退、列表切换 | 布局抖动、当前段落位置 | 不明显挤走阅读点；实验 CLS 报告可复现，不冒充真实用户数据 |
| NFR-03 | 主人登录页、私密文档与附件 | 会话、缓存、公开索引、退出/过期、错误输出 | 未授权无私密字节和可推断片段；公开 CDN 不混用个人响应 |
| NFR-04 | Markdown 恶意/异常输入 | script、危险 URL、允许/不允许的 HTML、畸形附件路径 | 不执行危险内容，不逃逸附件范围，报错能定位 |
| NFR-05 | 键盘、缩放、减少动态效果 | 焦点、标题语义、关闭弹层、触摸等价操作 | 核心路径可完成；文字无损，关键图与操作有可访问名称 |
| NFR-06 | 字体与素材 | 授权、字符覆盖、请求体积、失败回退 | 字体失败正文仍可读；来源和授权状态有记录，未确认不默认商用发布 |
| NFR-07 | 1000 条合成记录的索引 | 构建、搜索、筛选、内容更新时间 | 记录实际数量/耗时/体积，核心操作可用；据结果决定是否拆索引，不先承诺极端规模 |
| NFR-08 | 更新失败与恢复 | 构建失败、内容缺失、缓存失效和回滚 | 不覆盖可用版本，恢复后权限与附件仍一致 |

## 3. 视口与设备证据

- 自动化/人工预检：320、360、390、430、768、1024、1440 CSS px，首页、三类详情、列表、搜索、登录/退出和失败页。
- 手工连续缩放检查断点之间的宽度；页面超过视口 1px 的情况也定位原因，不用全局隐藏掩盖。
- 真实 iPhone Safari：记录设备型号、iOS/Safari 版本、网络条件，验证地址栏变化、安全区、横竖屏、软键盘、图片查看、目录、复制、浏览器前后退、登录与超时。
- 桌面 Safari 与 Chrome：按 M1 锁定版本记录；不同引擎结果分开。
- 无真实设备证据的状态写“真机未验证”，不能标为全平台通过；可继续本地实现，但不通过正式发布门槛。

## 4. 缺陷分级与退出条件

- S0：私密泄露、内容丢失、无法恢复等严重问题；立即阻止发布并处理。
- S1：核心页面打不开、手机不可读、核心导航/复制/登录失效、主要内容缺失；发布前全部关闭。
- S2：局部体验或次要功能问题；有记录、影响范围和安排，不能影响 P0 验收。
- S3：纯视觉微调或低影响细节；记录但不以无限打磨拖延闭环。

正式发布要求：P0 用例全部有证据并通过；S0/S1 为零；真机必测项完成；恢复演练完成；其余问题在发布说明中列明。未达到就标明测试版/预览阶段，不把进度数字当退出依据。

## 5. 证据记录格式

每次阶段验收在对应报告中记录：用例编号、源码/构建版本、内容样本、设备与环境、结果、证据路径、缺陷编号、复测结果。截图用相对路径保存在该阶段证据目录；不把包含私密内容的证据混入公开部署。
