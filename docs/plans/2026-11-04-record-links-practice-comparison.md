# 记录关联与复做对照实施计划

**目标：** 交付 F3 的显式记录关联和跨次菜谱实践对照，同时保持公开投影零私密泄露。

**架构：** Markdown v1 增加可选 `relatedRecords` 稳定 ID 数组。快照验证全库引用，详情投影按 public／owner 范围过滤目标并生成反向关联；UI 只消费已授权的详情响应，不在浏览器补取或过滤私密记录。菜谱复用同一关联集合，按 `occurredOn` 排序展示多次实践。

### Task 1：关联契约与权限安全详情投影

- 为 frontmatter、JSON Schema、共享 TypeScript 契约和快照校验增加关联字段。
- 拒绝重复、自关联、未知 ID 和超过 16 项的关联。
- 公开详情只投影公开已发布目标；主人详情投影全部主人目标；反向关联遵守相同权限。
- 用公开→私密、私密→公开、双向关联、无效目标和 contentRevision 回归固定行为。

### Task 2：桌面与 H5 关联及菜谱对照

- 阅读页展示相关记录，链接进入与当前权限范围一致的路由。
- 两条及以上可见菜谱关联显示日期对照；缺少日期的记录明确标为未记日期并排在最后。
- 公开页面没有私密目标标题、摘要、ID 或链接；主人页面可以看到获授权的跨次实践。
- 覆盖键盘、390／430px、减少动态效果和整页溢出。

### Task 3：内容维护兼容与完整验证

- 导入规范化、当前版本更新、历史恢复和导出保留关联 ID；不自动公开目标。
- 运行单元、集成、内容管理、双端浏览器、lint、typecheck、build 和项目结构检查。
- 保存报告、自检和交接；真实设备与生产发布不冒充完成。
