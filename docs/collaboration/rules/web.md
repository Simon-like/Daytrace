# 前端写入边界

Next.js App Router已建立，禁止重新选择框架或复制原型制造另一套应用。任务的允许路径以中央board为准。

模块主要修改自己的features和测试。src/app、共享layouts/components/styles、契约与锁文件由集成者串行维护，跨边界先提出影响和改动清单。

src/server只做Nest API适配与必要会话转发；内容读取、主人权限、附件与检索授权在Nest。不在浏览器过滤已经收到的私密字节。

D/D²与手写、中文阅读、专业移动排版保持；原型/合成/生产/真实设备的证据必须区分。文档和handoff写docs/collaboration，不回填features目录。
