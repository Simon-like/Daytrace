# 上下文入口

跨Kimi/Codex接力依赖仓库文件，不依赖双方自动知道对方聊天。

| 信息 | 唯一位置 | 更新时机 |
| --- | --- | --- |
| 用户最新要求与本轮边界 | [当前工作](当前工作上下文.md) | 用户改方向、接力或任务结束 |
| 长期产品/视觉/技术共识 | [项目记忆](项目记忆.md) | 共识真的变化时，不追加每轮流水 |
| 任务归属/依赖/状态 | [中央board](../collaboration/board.json) | 认领、提交与评审 |
| 具体任务上下文 | 任务卡 + [上下文模板](任务上下文模板.md) | 派发时补必要源文件，不复制整套文档 |
| 做过什么、怎样复现 | [交接目录](../collaboration/handoffs/) | 每次交付 |
| 阶段进度和证据 | [项目进度](../project/项目进度.md)及报告 | 集成与阶段验收 |

接手先读当前工作和自己的任务，再按引用找源文档。旧报告保留历史，不覆盖最新用户要求；临时推测不能写成稳定共识。共享记忆服务可以做检索提示，源文件始终优先。
