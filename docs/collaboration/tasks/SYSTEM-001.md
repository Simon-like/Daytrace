# SYSTEM-001：共享设计资产、桌面统一与入场编排

用户认可第二轮控件的方向，但认为页面之间仍缺少统一设计、没有整体出场动画，并要求移动端改为独立 H5 应用。本任务负责共享资产与桌面端，不将桌面页面继续压缩成移动版。

## 范围

- 将纸张、档案绿、墨色、圆角、阴影、控件尺寸与动效参数收敛为共享设计令牌。
- 在 `packages/ui` 本地维护 Button、Input、Select、Checkbox、Icon 与品牌组件，保留 Radix 无头行为和桌面现有功能。
- 在 `packages/content` 收敛公开内容读取、检索与归档状态能力，旧桌面入口保留兼容导出，不建立第二套业务接口。
- 统一首页、归档、搜索、阅读、关于与主人页的标题、操作区、记录元数据和控件语言。
- 增加短促的品牌稳定、标题与操作区分组入场；正文立即可读，不做长列表逐项 stagger，支持减少动态效果。

## 基线与写入

依赖 READER-002。以 UI-002 已获认可但未完成的控件交付为实现基线，保留其 Select 4 倍 CPU 长事件与正文脚本预算缺口，不宣称性能闭环。新 worktree 从最新主分支创建，以补丁带入前序未集成交付，不覆盖原现场。

只修改桌面应用、`packages/ui`、`packages/content`、对应测试、依赖锁定和本任务文档。独立 H5 由 MOBILE-001 接手；共享配置与锁文件仍串行处理。

## 验收

- 桌面各页面控件、间距、圆角、图标、焦点与状态来自同一套令牌和组件，无原生异常描边。
- 首屏入场只使用 opacity/transform，分组在 200–280ms 左右完成；JS 未加载与减少动态效果时内容立即可见。
- 原桌面 18 个浏览器流程、56 视口与既有单元／集成测试保持通过。
- 两端可复用内容 API 与状态逻辑，桌面旧导入路径兼容；lint、typecheck、build 和文档检查通过。
- 保存实际桌面截图和验证证据，明确 Select 性能与正文包体仍未闭环。
