## 目标与边界

本轮响应页面编排缺乏重点、内容过满、原生控件和异常焦点描边问题。采用 Tailwind CSS v4、按需 Radix Primitives 和仓库本地组件源码，不引入现成视觉皮肤，不改变 Next.js / Nest.js 技术方向。

本轮完成应用 shell、首页、归档、搜索、记录列表及正文桌面栅格修正。Markdown 解析和正文渲染体系没有重写，留作下一专项；真实 iPhone、生产环境和正式发布验收不在本轮证据范围内。

## 实施结果

- 首页只保留“最近留下的”主要内容焦点，移除厨房、随想等竞争模块和三张重分类卡；类别改为轻量文字索引。
- 侧栏只保留主导航和主人入口，移除重复分类、长寄语与页脚碎片。
- 归档记录使用桌面“左日期、右内容”和手机上下排列的日期索引；标签默认收起，按需展开。
- 新增本地 `Button`、`Input`、`Select`、`Checkbox`，统一 hover、disabled、键盘焦点与减少动效适配。
- 搜索输入移除浏览器 search 装饰，使用单一输入面；失败重试也迁移到本地按钮。
- 修正旧全局按钮样式未分层、覆盖 Tailwind 工具类的问题；为四个本地组件补充明确的焦点线型。
- 修正正文桌面 Grid 列分配：正文位于左侧宽栏，目录位于右侧；移动端目录与正文顺序不变。

设计依据见 `docs/design/视觉风格基线-v1.0.md` 第 8 节；方案调研见 `docs/research/2026-11-02-阅读型界面与无头组件调研.md`。
