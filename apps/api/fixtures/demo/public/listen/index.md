> 有时想把自己解释清楚，却忘了先把对方听完整。

## 留一点停顿

接到不同意见时，先复述自己听到的重点：“你担心的是交付时间，还是结果不确定？”

一句确认，比急着列出所有理由，更容易让讨论回到同一件事上。

## 给自己的提醒

表达清楚自己的边界，也给别人把话说完的空间。想不明白的时候，可以先记下来，不必马上变成一个成熟的观点。

1. 先听完事实和感受。
2. 再确认自己理解的重点。
   - 不急着替对方下结论。
   - 不把不同意见当成否定。
