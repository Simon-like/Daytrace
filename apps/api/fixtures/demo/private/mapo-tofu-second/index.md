这是一份私密演示记录，用来验证跨次实践只在主人空间展开，不代表真实生活数据。

## 这次只改一个变量

沿用第一次的备菜顺序和分次勾芡，把嫩豆腐换成老豆腐。其他用量保持不变，避免同时调整太多条件。

## 口感对照

老豆腐更容易保持形状，豆香更明显；入口不如嫩豆腐软滑。汤汁仍然分次加入，最后按实际咸度调味。

## 下一次

如果想保留软滑口感，就回到嫩豆腐，把下一次重点放在汆烫时间上。
