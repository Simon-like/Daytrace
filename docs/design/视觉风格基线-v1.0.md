日期：2026-10-30。状态：主题方向已获用户确认；实现参数为设计基线，需通过实际页面验证。

## 1. 已确认的方向

用户认可当前 D 系列的整体气质，明确要求保留手写装饰。停止无边界探索新主题，后续集中于排版、响应式与动效质量。

风格定义：安静、有温度的私人田野档案。技术观察、厨房实践与个人感想属于同一个人的积累；视觉表现精确，但不冷漠。

主参考是 THEME-009 的秩序、留白与精修质感，同时保留 THEME-004 的手写注记。不是照搬任一张图的全部像素。

## 3. 色彩与材质

以下是从 D² 提示词延续的实现起始值，并非从图片精确采样或由用户逐项确认的色值。

| 角色 | 起始值 | 使用规则 |
| --- | --- | --- |
| 阅读面 | `#F0F0E8` | 大面积安静底色，真实设备上检查偏色 |
| 档案侧栏 | `#29352C` | 深橄榄，承载导航，不扩大为正文背景 |
| 正文墨色 | `#252A25` | 正文与背景维持足够对比 |
| 辅助墨色 | `#73786B` | 日期、来源等次要信息，验证后必要时加深 |
| 修订强调 | `#9B6652` | 少量手写/锚点/状态强调，不能铺成大色块 |
| 结构线 | `#D4D7CC` | 分区和对齐，不把所有内容围成格子 |

不采用 E 的大面积黄紫撞色。低色差不等于低文字对比。

纸面只允许极轻、低成本的材质感；首版可先用纯色达到层次，再验证是否确需纹理。纹理不覆盖字形，不使用大体积背景视频、持续噪点动画或重滤镜。

## 4. 手写语言：必须保留，但有职责

- 保留：页边短注、少量日期感注记、个人提醒和“后来补充”的局部修订笔触。
- 正文、导航、代码、表格和关键状态采用清晰可读的印刷字，不全站手写。
- 每个可见页面区域最多一个主要手写视觉焦点，先以少量真正有意义的句子验证。
- 手写注记与原记录关联；没有来源的装饰短句只能标为设计示例，不冒充用户原话。
- 中文手写字体不得为一小段字阻塞整个正文。优先本机回退或小范围授权字形资源；下载字体前核对授权、字符覆盖和加载成本。
- 手机上页边注移动到相关段落之后，不能横跨正文、挤窄阅读列或叠在图片上。
- 装饰线条可作静态笔触；无需反复“写字”动画。手写内容同时有可访问的文本表示。

## 5. 字体、排版与图像

- 标题：现代中文宋体方向；正文：清晰中文黑体方向；日期与代码：等宽字体；手写为第四种有限角色，不能再无限增加字族。
- 手机正文以 17–18 CSS px、约 1.75–1.9 行高作为样稿起点；桌面阅读列约 36–42 个汉字宽。最终由真实长文确认。
- 长标题允许自然多行；多级标题、列表和表格有稳定的间距规则，不靠逐篇人工加空行。
- 代码可复制、局部横滑；表格保留二维关系；图片保留正文比例并可查看细节。
- 技术图解采用清晰细线和真实结构；生活照片保留自然光和实际过程，不能全靠生成图建立身份。
- 任何缩小字号、极淡文字、文字图片化或藏掉信息的方案都不能作为手机适配捷径。

## 6. 响应式与动效原则

桌面可有档案侧栏、主内容与生活栏目；手机重新组织阅读顺序，不把整个桌面等比缩小。

动效应表达展开、关闭、定位、状态反馈和空间关系。保留浏览器自然滚动，不接管滚轮，不让正文等待入场动画才可见。用户开启减少动态效果时有等价静态反馈。

详细行为、时长、测试矩阵与验收见 [产品需求文档](../product/PRD-v1.0.md)。当前图片不证明任何动效、响应式、性能或真机结果。

## 7. 风格变更管理

以后只要仍服务本基线，可调整字号、留白、断点、线条和动画参数。改变主视觉世界、引入大面积异色、去掉手写语言或推翻档案结构，需要先记录变更动机与用户反馈，不能悄悄替换已确认方向。

实现阶段应交付设计令牌、排版样张、响应式规则、动效样例及截图证据，而不是继续只交付静态整图。

## 8. 2026-11-02 界面编排与组件实施补充

用户实测反馈当前Demo“功能编排乱、内容排得满、原生控件未完成”。这不推翻D/D²，而是修正实现偏离：简约不等于密集的小字、细线和卡片。调研与采用理由见[阅读型界面与无头组件调研](../research/2026-11-02-阅读型界面与无头组件调研.md)。

### 信息层级

- 首页唯一主体是最近记录；首屏只保留一句主题、一个主要归档入口和轻量分类索引。厨房、随想、重复分类导航不再同时竞争首页注意力。
- 归档先展示记录结果，类别用单一Select，标签默认收起；搜索先展示明确标签和单一输入面，不用多层边框制造“设计感”。
- 每个页面最多一处手写注记。侧栏只保留主要导航和主人入口，不再重复三个分类及多段寄语。

### 当前设计令牌

| 角色 | 色值/字族 | 用途 |
| --- | --- | --- |
| 纸白 | `#F4F4ED` | 全局阅读面 |
| 深橄榄 | `#243128` | 侧栏、主要按钮与选中状态 |
| 正文墨色 | `#202720` | 标题与正文 |
| 辅助墨色 | `#667065` | 次要说明，保持可读对比 |
| 修订色 | `#93634F` | 少量手写、焦点与关键状态 |
| 结构线 | `#D8DDD3` | 分区，不包围所有内容 |

标题沿用中文宋体方向，正文沿用中文黑体，日期/代码使用等宽，手写只作第四角色。记录列表以真实日期形成“时间索引”：桌面为左日期右标题，手机改为上下顺序，不使用无意义编号或卡片网格。

### 本地组件约束

Tailwind CSS负责令牌、布局与状态工具类；本地`components/ui`维护组件API和视觉。Select/Checkbox采用Radix无头行为，Button/Input保留原生语义。所有交互控件必须有统一`:focus-visible`、disabled、44px最小触控目标与减少动效适配；不能用`outline:none`后不提供等价焦点。

第一轮只覆盖shell、首页、归档、搜索与记录列表，并修正正文页明显容器问题。Markdown解析、正文排版组件和更多无头组件在后续专项中处理，不在本轮同时重写。
