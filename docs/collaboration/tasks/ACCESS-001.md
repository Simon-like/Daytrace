# ACCESS-001：主人访问与附件隔离

## 目标

实现Next owner/server适配及Nest auth/assets；权威会话/权限集中Nest，SSR受控转发，附件和所有派生输出有访问边界。

## 交付与验收

登录/退出/过期/白名单、私密正文/附件/搜索/缓存负例，对应AC-13与NFR-03/04。提供可复用策略给content/search，不复制业务模块。

先读[研发交接](../../architecture/研发交接与任务编排.md)、[技术架构](../../architecture/技术选型与研发路径.md)与[CI/CD方案](../../architecture/CI-CD与运维建设方案.md)，再按PRD和本任务验收项细化。

## 边界与交接

状态、owner、依赖与允许路径只在中央board维护。依赖满足仍需实际派发/认领；不得绕过锁文件/共享路由集成规则。独立worktree由中央协调者认领，不覆盖自己的台账副本。跨范围变更交集成者处理。交接注明SHA、运行方式、实际验证、未验证和合并/部署状态；不以自检冒充独立评审。
